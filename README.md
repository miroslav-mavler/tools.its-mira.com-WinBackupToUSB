# tools.its-mira.com-WinBackupToUSB
Manual or automatic tool driven predefined user data backup to external USB device with autodetect correct device and device condition check before backuping. It goes to do first full backup followed incremental backups.

See docs/PLAYWRIGHT-MCP.md for setting up the Playwright MCP server in VS Code/Copilot to help validate and automate browser-assisted tasks.
